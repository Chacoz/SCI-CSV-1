# Photos du bien

Déposez ici les photos de la maison et des chambres, puis renseignez leur chemin
dans l'espace gestion (Chambres → Éditer → champ « Photo »).

Exemple : une photo nommée `chambre-1.jpg` placée dans ce dossier se référence par
`/photos/chambre-1.jpg`.

Formats conseillés : JPG ou WebP, largeur ~1200 px, < 500 Ko par image.
